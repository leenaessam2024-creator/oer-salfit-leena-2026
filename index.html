🔗 2- شو علاقة H5P و GitHub؟

سألتي ليش بنستخدم الاثنين مع بعض؟ هاي الإجابة:

👩‍🍳 H5P = الطباخ
بيعمل الكويز، لعبة تحدي الوزير، الفيديو التفاعلي. بيعطي علامة و feedback فوراً. بس بدون صفحة، بيضل على كمبيوترك.
تفاعل
🏛️ GitHub = المطعم والثلاجة
بيحفظ الكود، بيعطيكي رابط مجاني، وبيحفظ كل نسخة (عندك 13 نسخة). أي معلم بيقدر يشوف الكود وياخذ نسخة.
حفظ ونشر
مع بعض: H5P يعمل التفاعل + GitHub ينشره للعالم = OER حقيقي يحقق الـ 5R حسب يونسكو

♻️ 3- إطار 5R حسب يونسكو - تطبيق في سلفيت

1. Retain - احتفاظ
مدرسة كفر الديك تحتفظ بنسخة من الكويز على كمبيوتر بدون إنترنت - USB
2. Reuse - إعادة استخدام
معلم في سلفيت يستخدم نفس الكويز لطلابه بدون ما يكتب من الصفر
3. Revise - تنقيح
تعدلي سؤال ليتناسب مع صف رابع بدل سابع
4. Remix - مزج
تدمجي كويز لينا + فيديو Canva + خريطة سلفيت = مورد جديد
5. Redistribute - إعادة توزيع
