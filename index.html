توصية يونسكو 2019: مواد تعليمية مفتوحة بترخيص مفتوح تسمح بـ Retain, Reuse, Revise, Remix, Redistribute

🔗 2- شو علاقة H5P و GitHub؟

👩‍🍳 H5P = الطباخ
بيعمل الكويز، لعبة تحدي الوزير، الفيديو التفاعلي. بيعطي علامة فورية. بدون صفحة، بيضل على كمبيوترك بس.
🏛️ GitHub = المطعم والثلاجة
بيحفظ الكود، بيعطيكي رابط مجاني، وبيحفظ كل نسخة عملتيها. أي معلم بيقدر ياخذ نسخة.
مع بعض: H5P تفاعل + GitHub نشر مجاني = OER حقيقي CC BY 4.0

♻️ 3- إطار 5R - تطبيق في سلفيت

1. Retain - احتفاظ
مدرسة كفر الديك تحتفظ بنسخة Offline على الكمبيوتر - USB
2. Reuse - استخدام
معلم في سلفيت يستخدم نفس الكويز بدون كتابة من الصفر
3. Revise - تنقيح
تعدلي السؤال ليناسب صف رابع بدل سابع
4. Remix - مزج
تدمجي كويز + فيديو Canva + خريطة سلفيت = مورد جديد
5. Redistribute - توزيع
تنشريه على GitHub Pages برابط مجاني - كل فلسطين تستفيد - CC BY 4.0 مع ذكر اسمك
